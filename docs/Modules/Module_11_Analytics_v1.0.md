# Module_11_Analytics_v1.0

## Цель

Аналитика цен, смет, закупок, поставщиков и строительства.

Module 11 является каноническим владельцем функции `PRICE_DYNAMICS`. Legacy-код `MODULE_14_PRICE_HISTORY` остается только alias/redirect для совместимости старых ссылок, прав, audit history и dashboard layouts.

## Бизнес-логика

- Аналитика строится на накопленных данных платформы.
- Аналитические выводы должны быть объяснимыми.
- Динамика цен строится по `PriceHistory` и данным Material Hub, но не меняет материалы, цены или источники.
- Виджеты аналитики цен используют source/canonical module `MODULE_11_ANALYTICS`.

## Сущности

- AnalyticsReport
- Metric
- PriceTrend
- Forecast
- PriceDynamicsSlice
- SavedAnalyticsFilter

## Ограничения

- Аналитика появляется после данных и алгоритмов.
- AI может анализировать, но не является источником истины.
- Module 14 не является самостоятельным активным модулем; это legacy alias на `MODULE_11_ANALYTICS / PRICE_DYNAMICS`.
